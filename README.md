# PathFinder

PathFinder is my attempt to create a pathfinding app in my favorite programing language.

![Pathfinder](images/pathfinder.png)

## Usage

Press H for help

![Pathfinder Help](images/pathfinder_help.png)

on linux run
`release/pathfinder`
or build from source
`cargo build`
Press and hold corresponding letter and drag or click to set

W - Create walls
H - Help
S - Set start cell
G - Set end goal

Space - Solve with a* algorithm
